## 🚀 Flagship & Featured Projects

### 1. [Conformal Helmet-Integrated Antenna System — Smart India Hackathon 2026](https://github.com/barath0508)
*RF Engineering, Microstrip Patch Arrays, Dual-band (UHF + L-Band), EM Shielding, Tactical Hardware*
> Tactical RF communication system engineered for NSG Close Quarter Battle (CQB) & Counter-Terrorism (CT) operations, embedding a flexible microstrip patch antenna array directly into a ballistic helmet to replace snag-prone vest-mounted whip antennas.
> - **Dual-Band Operation**: Simultaneous UHF tactical radio communications and L-band live helmet-camera video transmission.
> - **Radiation Pattern & Safety**: Integrated high-attenuation RF shielding layer minimizing Specific Absorption Rate (SAR) / cranial radiation exposure while directing gain upward and outward for extended link distance.
> - **Rugged Tactical Interface**: Low-profile, weather-sealed coaxial feed designed for seamless coupling to handheld radios without compromising helmet ballistic NIJ ratings.
