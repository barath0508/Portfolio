## 🚀 Flagship & Featured Projects

### 1. [iCreatePDF — 100% Client-Side PDF Utilities](https://icreatepdf.online)
*Next.js 16, TypeScript, Tailwind CSS, WebAssembly (WASM), Web Workers*
> A fast, free, and privacy-focused document processing suite featuring **37+ in-browser PDF utilities**. By utilizing client-side WebAssembly and modern web APIs, all file conversion, page reordering, compression, and booklet imposition occurs directly inside local browser memory buffers with zero remote server transfers.
> - **Live Production**: [icreatepdf.online](https://icreatepdf.online)
> - **GitHub**: [barath0508/iCreatePDF](https://github.com/barath0508/iCreatePDF)

### 2. [Solar Tracker 3D & Telemetry Dashboard](https://solar-tracker-pi-jade.vercel.app)

> - **Live Demo**: [solar-tracker-pi-jade.vercel.app](https://solar-tracker-pi-jade.vercel.app)
> - **GitHub**: [barath0508/Solar_Tracker](https://github.com/barath0508/Solar_Tracker)
